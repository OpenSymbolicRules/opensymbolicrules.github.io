# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| main (the deployed site) | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities in the site, its generator or its
build workflow, and figures on the site that misrepresent the source
repositories, through a GitHub Security Advisory (GHSA) on this repository:
<https://github.com/OpenSymbolicRules/opensymbolicrules.github.io/security/advisories/new>.

Do not open public issues for security vulnerabilities.
